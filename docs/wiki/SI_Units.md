# SI / units convention

Owner: Data Scientist + Ops. Consumer: ADA.

| Quantity | Unit | Ada |
|----------|------|-----|
| Human/item mass | g | `Mass_Grams` |
| Vehicle / worn suit mass | kg | `Mass_Kilograms` |
| Pressure | absolute kPa | |
| Temperature | K SoT; C telemetry | |
| Power | kW demo / MW docs | |
| Acceleration | ×g0 (`G_Load`) | |
| Time | s (MET) | |

**Storm exterior profile name:** `Mars_Thin` (or equivalent) at **20 kPa** — not Earth 70–85 kPa.

Game scalars (AP, %, tile indices) are non-SI.
