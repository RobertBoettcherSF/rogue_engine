# Story arc — bunker → rocket → station

Lean narrative over **phase→world profile** swaps. Communicator = STORY + systems voice. **ALERT/CAUTION never wait on STORY; STORY never mutates SI.**

## Phases

| Phase | Where | SI profile (changes) | STORY / PA |
|-------|--------|----------------------|------------|
| **1 Bunker** | ops room | Cabin ~101 kPa, O2~21 kPa, g=1.00 | Welcome; “proceed to pad” |
| **2 Pad / board** | airlock → capsule | Suit optional; ΔP checks | ANNOUNCEMENT: boarding |
| **3 Ascent** | rocket | **G climbs** (greyout/blackout); cabin P/O2 held | Technical-difficulties if scrubber glitch; wrist hard to raise |
| **4 Coast** | transfer | g→~0 (micro-g flag); cabin stable | Quiet STORY / MET |
| **5 Dock / station** | Tiangong-like | Cabin bands locked; exterior vacuum/thin | Welcome to &lt;Planet/Station&gt; |

Destination **&lt;Planetname&gt;** / station name from scenario pack (Earth / Mars / Titan / …).
