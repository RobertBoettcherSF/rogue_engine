# Worldbuilding locks (from Robert)

Hard SF. Passenger = P.

## Polity

One government, one species. Humans live underground or on stations across multiple solar-system bodies (~2129 + advanced AI). Ships/stations run by that government. Arc v0 destination: generic human space station (Mars/Titan surface later).

## Gravity

Mastered gravitation vaguely: g_eff only (x g0). Force field = set target g_eff.

## Play layout

Rogue-style: ASCII map on top; message at most 4 lines x 80 chars; under that 4 values P_kPa O2_kPa g_eff uSv_h. Sensors update while P reads. ALERT mid-message: WARNING blinks 3x pause 3x then ALERT takes slot.
